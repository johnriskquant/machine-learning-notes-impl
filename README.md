# Machine Learning Specialization Notes & Implementations

A comprehensive, production-ready reference repository containing structured notes, mathematical breakdowns, and applied code for the **DeepLearning.AI and Stanford Online Machine Learning Specialization** taught by Andrew Ng.

This repository is built to be highly forkable and serves as a practical bridge between the specialization's intuitive explanations and production-level code. It organizes the core curriculum—covering supervised learning, advanced neural network architectures, and unsupervised systems—into a reliable local engineering reference.

### ⚡ What's Inside

* **Foundational Notes:** Clean, high-signal documentation breaking down algorithmic intuition, model development lifecycle practices, and evaluation metrics.
* **Rigorous Formulations:** Standard LaTeX implementations tracking cost functions, vectorized gradient descent equations, regularization operations, and neural network layer mechanics.
* **Applied Implementations:** Step-by-step custom Python scripts and interactive Jupyter Notebooks mirroring the curriculum's progression from core regression up to deep reinforcement learning.

### 🎯 Who is this for?

* **Engineers Upskilling in AI:** A centralized environment to solidify your conceptual grasp of how modern machine learning models function under the hood.
* **Interview Candidates:** A structured training resource for drilling machine learning engineering fundamentals, diagnostics, and algorithm mechanics for technical interview loops.
* **Practitioners Seeking a Local Reference:** A clean, searchable index of core algorithms, evaluation frameworks, and model architecture diagrams.

### 📁 Repository Architecture

#### 📉 Course 1: Supervised Machine Learning: Regression and Classification
* [Week 1: Introduction to Machine Learning](./supervised-learning/week-1-introduction) — Supervised vs. unsupervised learning, cost function mechanics, and gradient descent basics.
* [Week 2: Regression with Multiple Input Variables](./supervised-learning/week-2-multiple-variables) — Vectorization, feature scaling, learning rate selection, and polynomial regression.
* [Week 3: Classification](./supervised-learning/week-3-classification) — Logistic regression, decision boundaries, overfitting diagnostics, and regularized cost functions.

#### 🧠 Course 2: Advanced Learning Algorithms
* [Week 1: Neural Networks](./advanced-algorithms/week-1-neural-networks) — Forward propagation, matrix multiplication layers, and TensorFlow model building.
* [Week 2: Neural Network Training](./advanced-algorithms/week-2-network-training) — Backpropagation calculus, activation functions (ReLU, Softmax), and optimization variants.
* [Week 3: Advice for Applying Machine Learning](./advanced-algorithms/week-3-ml-advice) — Bias/variance diagnostics, learning curves, error analysis, and iterative development workflows.
* [Week 4: Decision Trees](./advanced-algorithms/week-4-decision-trees) — Information gain, entropy metrics, tree ensembles, random forests, and XGBoost mechanics.

#### 🤖 Course 3: Unsupervised Learning, Recommenders, Reinforcement Learning
* [Week 1: Unsupervised Learning](./unsupervised-systems/week-1-unsupervised) — K-means clustering optimization and Gaussian distribution anomaly detection pipelines.
* [Week 2: Recommender Systems](./unsupervised-systems/week-2-recommenders) — Collaborative filtering, content-based filtering, deep learning for recommendations, and PCA.
* [Week 3: Reinforcement Learning](./unsupervised-systems/week-3-reinforcement) — Markov Decision Processes, Q-learning mechanics, bellman equations, and continuous state spaces.
